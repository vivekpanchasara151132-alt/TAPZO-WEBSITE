# TAPZO — Smart NFC Business Solutions

**Tap. Connect. Grow.**

Official static website for **TAPZO – Smart NFC Business Solutions** (Gujarat, India), built with semantic HTML5, modern CSS3, and vanilla JavaScript.

## Structure
- `index.html` — Main brand website (Hero, About, How It Works, Products, Why Choose TAPZO, Industries, Interactive Demo, FAQ, Contact, Footer)
- `profile.html` — Interactive Digital Business Landing Page preview for TAPZO Premium & Pro packages
- `css/styles.css` — Dark luxury design system (`#111315`, `#1C1D1F`, `#D6B779`)
- `js/main.js` — Navigation, scroll reveals, NFC/QR demo switcher, package pre-selection, and contact form validation
- `assets/` — SVG favicon and industry imagery
- `vercel.json` — Vercel static hosting configuration (`cleanUrls`, security & asset caching headers)
